# 샘플 권리·공개 기준

1. 정부기관 공개 웹페이지도 이미지별 저작권·공공누리·제3자 권리를 확인한다.
2. catalog의 rights.status=unreviewed이면 저장소에 원본 이미지·썸네일을 재배포하지 않는다. 모델 입력으로 자동 전송하지 않는다.
3. 공공누리 표시를 확인하면 유형, 표기 위치, 확인일, 출처표시·변경·상업이용 조건을 기록한다. 로고·인물·민간 제작물 예외도 살핀다.
4. 원문 링크, 자체 작성한 관찰·분류와 원본 이미지의 라이선스를 구분한다.
5. 생성물에 정부 인증·공식 발표처럼 보이는 허위 로고·표장을 넣지 않는다.
6. 사용자가 명시적으로 공개를 승인하지 않은 기획안·생성물은 로컬 실행 폴더에 보관한다.
7. 외부 코드 도입은 원출처·커밋·라이선스·수정내용을 기록한다.
