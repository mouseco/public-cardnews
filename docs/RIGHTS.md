# 공개 자료 사용 조건

## 자체 코드·문서·프롬프트
[MIT](../LICENSE) 적용. 복사·수정·배포·상업적 이용 시 저작권 고지와 라이선스 전문을 보존한다. 제3자 코드는 [고지문](../THIRD_PARTY_NOTICES.md)의 별도 조건을 따른다.

## 직접 생성한 PNG와 공개 예제
저장소 관리자가 보유하고 허락할 수 있는 권리의 범위에서, 공개 승인된 제작 샘플 및 가상 기관 예제 PNG의 다운로드·디자인 참고·수정·재배포·상업적 활용을 MIT 조건으로 허용한다. 이를 독점적 권리나 모든 이미지 요소에 대한 권리 보증으로 해석하지 않는다.

- 공식 기관 홍보물·정부 인증·기관의 추천을 의미하지 않는다.
- 실제 사용 시 기관명·서비스명·날짜 등 원고를 본인 상황에 맞게 교체한다. 원본의 기관 안내인 것처럼 배포하지 않는다.
- 사진형 인물은 생성 이미지이며 실제 기관 직원이 아니다.
- 로고·상표·초상·제3자 저작물의 권리는 별도다. 사용자는 공개 목적에 맞는 권리와 사실을 확인한다.
- 생성 이미지의 저작권 성립이나 독점성, 제3자 권리 비침해를 보장하지 않는다. AI 생성물임을 숨겨 실제 기록 사진처럼 사용하지 않는다.
- S06은 원고 외 배경 문구가 남은 디자인 실험안으로 분리한다. 그대로 실제 게시용으로 권장하지 않는다.

## 외부 참고 사례 E 항목
권리는 각 원권리자에게 있다. MIT 대상이 아니다. 공개 웹페이지라는 이유로 복제·수정·상업적 이용·모델 참조 입력이 허용되는 것은 아니다. 목록의 rights가 unreviewed인 동안 원문 링크로 확인하며, 원본 파일을 저장소에 재배포하거나 모델에 자동 전송하지 않는다. 공공누리·제3자 권리·로고·인물 조건을 개별 확인한다.

## 내부 자료·인증
사용자가 범위를 지정해 공개 승인한 샘플만 배포한다. 다른 내부 수치·문서·원고·로그·토큰·개인 경로까지 공개하지 않는다. 실행기는 로그인된 Codex를 호출하므로 신뢰할 수 있는 입력과 별도 작업 폴더로 실행한다. workspace-write는 완전한 보안 인증이 아니다.
