# 두 축의 분류

초기 분류안이며 완성된 표준이 아니다. 현재 3개 샘플로 확인한 유형과 확장 후보를 구분한다. 여러 부처 사례를 추가한 뒤 중복·경계를 조정한다.

## 내용 구성 그룹
- result-summary: 질문/배경 → 주요 결과 → 의미 → 참여·후속 안내. 조사·이용현황 결과용. 교육지표 샘플의 수치 비교 구성을 참고.
- service-guide: 관심 유도 → 서비스 소개 → 기능·이용방법 → 이용 경로. 교육부 AI 서비스 샘플에서 확인.
- participation: 대상 문제 → 참여 내용 → 대상·조건 → 신청 경로. 중기부 참여 안내 샘플에서 확인.
- policy-change: 변경 배경 → 전후 비교 → 대상·시행일 → 행동 안내. 추가 샘플 확보 필요.
- faq: 질문 → 답변 → 예외·주의 → 확인 경로. 추가 샘플 확보 필요.

## 시각 디자인 그룹
- public-blue-3d: 흰 배경·남색 굵은 제목·파란 입체 오브젝트·중앙 핵심 정보. 중기부 샘플에서 관찰.
- friendly-service-3d: 밝은 배경·굵은 제목·여러 색의 입체 아이콘·항목별 정보 박스. 교육부 AI 샘플에서 관찰.
- illustrated-statistics: 캐릭터·큰 통계·비교 그래프·설명 말풍선. 교육지표 샘플에서 관찰.

## 기록 항목
제목 위치, 글자 위계, 색상, 여백, 장식/정보 비중, 일러스트 재질, 그래프 방식, 표지/본문/마무리 변형, 한글 줄바꿈, 권리 조건.

샘플의 색·구성 원리를 분석하되 문구·캐릭터·로고·고유 일러스트를 그대로 복제하지 않는다. 추천은 인기순이 아니라 독자·목적·내용 밀도·사용자 취향을 기준으로 한다.
