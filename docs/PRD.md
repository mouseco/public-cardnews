# 제품 요구사항 v0.1

## 사용자와 목표
정책·사업·조사·성과를 안내하는 공공기관 실무자가, 실제 공공 카드뉴스 샘플을 보고 디자인을 선택한 후 프롬프트와 완성 이미지까지 얻도록 한다.

## 범위
- 정부기관 원문을 근거로 샘플을 기록하고 그룹별 탐색을 지원한다.
- 내용 구조와 시각 스타일은 독립 분류한다. 샘플 하나에 복수 태그를 허용한다.
- 기획안 유무에 따라 흐름을 분기한다.
- 기획이 없으면 근거 자료와 필수 정보만 확인하고 기획안을 제안한다.
- 이미 승인된 문구·수치·장수는 보존한다. 부족한 사실은 사용자에게 질문한다.
- 디자인 추천에는 실제 샘플, 맞는 이유, 조정할 부분을 함께 제공한다.
- 디자인 선택 전에는 임의로 생성하지 않는다.
- 승인 후 첫 장부터 마지막 장까지 순차 생성한다. 첫 생성 이미지를 후속 장의 스타일 참조로 사용한다. 권리가 확인되지 않은 정부 이미지는 외부 모델 입력으로 자동 전송하지 않는다.
- 매 장 원고·프롬프트·결과를 연결하고 성공한 장은 재생성하지 않는다.

## 생성 프로세스 3번: 검수 및 전달
장수·파일 유효성·한글·숫자·단위·주석·참여 경로·디자인 일관성을 검수한다. 오류 장만 고친 뒤 이미지와 프롬프트를 함께 제공한다. 미확인 사항은 검수 완료로 표시하지 않는다.

## 출력 계약
run/brief.json: 사용자 승인 원고, 독자, 목적, 출처, 장수
run/design.json: 선택한 디자인 ID, 참조 출처, 사용자 선택 상태
run/prompts/01.md ...: 장별 완성 프롬프트
run/images/01.png ...: 네이티브 생성 원본
run/manifest.json: 장별 상태·파일·실제 크기·요청 모델·확인된 모델·실행기 버전
run/review.md: 검수 결과와 미확인 사항

각 실행 폴더는 비공개이며 git 추적에서 제외한다. 실제 이미지가 없으면 완료로 표시하지 않는다.

## 비목표
자동 게시, SNS 계정 연결, 기관 내부자료 자동 수집, 설문 시스템 구축, 사용자 대신 정책·수치 발명, HTML 기반 카드 캡처, 제3자 스킬 무단 설치.

## 권한 경계
공개 소스 수집과 재배포는 별개다. 원문 링크·출처 기록은 기본으로 하고, 이미지 복제·공개·외부 모델 전송은 이용조건을 각각 확인한다. 사용자 문서의 공개는 저장소 공개 승인과 별개다.
