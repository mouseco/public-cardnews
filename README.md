# Public Cardnews · 공공 카드뉴스

정부·공공기관의 실제 카드뉴스를 참고해 디자인을 선택하고, GPT 이미지 생성용 프롬프트와 완성 이미지를 함께 만드는 에이전트 스킬 프로젝트입니다.

> **현재 단계: 프로젝트 착수 / 설계 v0.1.** 공식 샘플 3건의 출처·분류와 스킬 초안을 포함합니다. 자동 수집, 설치형 배포, 이미지 생성 오케스트레이터는 아직 구현하지 않았습니다. 완성품이나 정부 공식 서비스가 아닙니다.

## 목표

- 정부부처·공공기관의 공개 카드뉴스를 수집하고 **내용 구성과 시각 디자인을 따로 분류**합니다.
- 사용자가 디자인을 선택한 뒤에만 해당 스타일로 제작합니다.
- 이미지 생성은 Codex 내장 이미지 도구를 사용하는 실행기에 연결합니다. HTML 캡처를 최종 제작 방식으로 사용하지 않습니다.
- 완성 이미지뿐 아니라 장별 프롬프트·출처·제작 기록도 제공합니다.

## 사용자 흐름

1. “공공 카드뉴스 만들어줘” 요청
2. **기획안이 있으면:** 원고·장수·핵심 문구를 보존하고 디자인 추천 단계로 이동
3. **기획안이 없으면:** 목적·독자·근거 자료를 바탕으로 내용 구성 유형을 추천하고 기획안 작성 → 사용자 승인
4. 승인된 기획안에 맞는 디자인 후보와 **실제 샘플** 제시 → 사용자 선택
5. 장별 이미지 생성 프롬프트 작성 → 선택한 디자인으로 전체 카드 순차 생성
6. 한글·수치·일관성 검수 → 문제가 있는 장만 수정
7. PNG 원본 + 장별 프롬프트 + 출처·검수 결과 제공

사용자가 준 핵심 문구와 세부 조건을 우선합니다. 빈 내용을 가짜 수치·일정·혜택으로 채우지 않습니다. 사용자의 문구 수정은 명시적으로 제안하고 승인받습니다.

## 실행기 방향

기존 `JimLiu/baoyu-skills`의 `baoyu-codex-imagegen`을 연결 후보로 채택합니다. 아직 이 저장소에 실행기를 복제하거나 설치하지 않았습니다. Codex 로그인 기반 실행을 우선하고, API 키 기반 경로로 자동 전환하지 않습니다. 운영체제별 실행 파일과 인증을 분리하며 개인 PC 경로를 하드코딩하지 않습니다.

이미지 모델명은 런타임에서 확인합니다. 요청 모델명만으로 실제 모델이 선택됐다고 표시하지 않습니다.

## 공개 범위

기관 내부 원고, 사용자 생성물, 인증정보는 저장소에 포함하지 않습니다. 샘플 이미지의 재배포 권리가 확인되기 전에는 **출처 링크·분석 메타데이터만** 제공합니다. 정부 공개물이라는 이유만으로 로고·사진·캐릭터까지 자유이용 가능하다고 가정하지 않습니다.
