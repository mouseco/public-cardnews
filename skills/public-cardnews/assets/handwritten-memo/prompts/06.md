# 1. Scene
한국어 AI 아침 브리핑을 사람이 직접 정성껏 써서 동료에게 건네는 손글씨 메모 한 장. 시리즈 6번째. 텍스트가 화면의 중심인 노트 디자인. 따뜻한 크림색 종이 한 장이 캔버스를 채우고, 짙은 먹색 펜으로 쓴 또박또박 읽기 쉬운 한국어 손글씨. 제목은 두꺼운 펜, 본문은 일정한 굵기의 펜. 손으로 긋는 밑줄, 연노랑 형광펜, 아주 작은 여백 메모 표시만으로 강조한다. 전체 면적의 85%는 텍스트와 텍스트 사이 여백. 그림 대신 문장과 필기의 리듬이 디자인을 만든다. 손글씨는 사람의 온기가 있으면서 획이 선명하고 글자 구조가 정확하다. 종이의 위아래 여백 6%, 좌우 여백 8%. 본문은 여유 있는 줄간격으로 왼쪽 정렬. 섹션별로 자연스럽게 한 줄을 띄워 메모한다. 첫 장 참조가 있으면 해당 종이색·손글씨·필기구·밑줄만 계승하고 이번 장 카피를 새로 적는다.
# 2. Camera
종이를 정면에서 본 평면 판면. 글 전체가 똑바로 읽히며 얇은 종이 결이 보인다.
# 3. Lighting
따뜻하고 균일한 자연광 5000K, 종이의 평평한 밝기.
# 4. Color grading
크림 종이 #F8F3E8, 본문 먹색 #30342F, 연노랑 형광펜 #F5DD85, 주석 회갈색 #777267, 밑줄 녹색 #486554.
# 5. Texture/Medium
실제 종이에 펜으로 쓴 읽기 쉬운 한국어 손글씨 메모. 일정한 획 두께, 약간의 필압 변화, 은은한 종이 섬유. 본문도 손글씨지만 정돈된 줄 맞춤과 충분한 글씨 크기.
