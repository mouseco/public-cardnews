# S07 · 텍스트 중심 손글씨 메모형

AI·뉴스 브리핑, 업무 요약처럼 문장을 읽어야 핵심이 전달되는 카드뉴스에 사용한다. 기존 메모지형 S02와 별도로 선택한다. 손글씨 메모형을 선택하면 입체 그림·인포그래픽·도표보다 텍스트를 중심으로 구성한다.

## 디자인 기준
- 크림 종이 #F8F3E8, 먹색 글씨 #30342F, 연노랑 형광펜 #F5DD85, 회갈색 주석 #777267, 녹색 밑줄 #486554.
- 또박또박 읽히는 한국어 손글씨. 제목은 두꺼운 펜, 본문은 일정한 획 두께와 약간의 필압 변화로 작성한다.
- 텍스트와 문단 여백이 화면의 약 85%를 차지하게 한다. 상하 여백 6%, 좌우 8%, 왼쪽 정렬을 기준으로 한다.
- 소제목·본문·출처의 크기를 각각 통일한다. 긴 문장은 글씨를 줄이지 않고 어절 단위로 줄바꿈한다.
- 박스·입체 아이콘 대신 문단 간격·손으로 그은 밑줄·소수의 형광펜 강조로 읽는 순서를 만든다.

## 내용 기준
제목만 남기는 과도한 축약을 피한다. 각 소식에서 ‘무슨 소식인지 → 주요 내용 → 업무에서 확인할 점’이 읽히게 한다. 예정·시범운영·집계 단위·활용 제안 등 사실을 해석하는 데 필요한 조건은 보존한다. 원고에 없는 평가·성과를 추가하지 않는다.

## 생성과 검수
첫 장을 생성하고 확인한 뒤 같은 이미지를 후속 장의 스타일 참조로 전달한다. 정확한 원고는 장별 프롬프트에 넣고 손글씨도 전 장 직접 대조한다. 텍스트를 이미지 위에 사후 합성하지 않는다. 오류가 있는 장만 재생성한다. 요청 화면비는 4:5이며 생성기가 반환한 네이티브 크기를 유지한다.
