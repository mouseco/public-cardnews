# 직접 생성한 표지 디자인 6종

같은 표지 문구로 디자인을 비교한 공개 승인 샘플입니다. 정부기관 원본 이미지를 복제한 갤러리가 아닙니다. 공식 사례의 색·배치·정보 위계를 참고해 각각 생성했습니다.

하단 웹주소를 제거한 이미지와 주소를 제외한 생성 프롬프트, 실제 편집 지시문을 제공합니다. 생성 결과는 비결정적이므로 프롬프트 재실행 시 동일 픽셀이 보장되지는 않습니다.

## 사용 기준

번호나 이름으로 스타일을 선택한 뒤 새 원고에 맞게 재작성합니다. 샘플의 기관 문구·날짜를 다음 작업에 자동 승계하지 않습니다. 하나의 시리즈는 선택 스타일을 유지하고, 독립 디자인 비교는 각 안을 별도로 생성합니다.

06 사진형 인물은 생성 이미지이며 실제 기관 직원이 아닙니다. 배경 벽의 원고 외 장식 문구는 남아 있으므로 실제 업무 게시용 재사용 전 점검합니다.

정부기관의 공식 서비스·인증을 의미하지 않습니다. 샘플 공개 허용은 기관 로고·캐릭터·외부 원본 이미지 사용권을 포괄하지 않습니다.
