# 공공 카드뉴스

공공기관·사내 직원 대상 정책 안내, 이용현황, 설문 참여 카드뉴스를 제작한다. 외부 Codex 이미지 실행기를 이용한 순차 생성·육안 검수 절차를 제공한다. 실행기와 인증은 이 저장소에 포함하지 않는다.

## 시작과 기획

이미 기획안·장수·문구가 제공됐다면 보존한다. 기존 분석자료가 있으면 접근 가능한 최신 원본을 먼저 찾아 읽는다. 독자·목적·사실 근거·참여 경로 중 회수할 수 없는 필수 정보만 질문한다.

저장소의 docs/TAXONOMY.md와 catalog/sources.json을 참고해 장별 제목·핵심 메시지·시각 표현을 제안한다. 없는 수치·일정·효과를 만들지 않는다.

짧은 이용현황·설문 안내는 다음 4장 구성을 후보로 사용하되 사용자 승인안을 우선한다.
1. 표지: 주제를 정확하게 밝히고 자연스러운 질문으로 관심을 유도한다.
2. 핵심 수치: 이용 규모·변화를 큰 숫자와 짧은 그래프로 보여준다.
3. 경험 질문: 분석의 한계와 실제 경험을 묻는 질문을 연결한다.
4. 참여 안내: 대상·기간·참여 경로와 결과 활용 목적을 모은다.

정확한 제목을 보고서식 문장 나열로 해석하지 않는다. 부자연스러운 수사와 과장을 피하고 직원이 알아야 할 내용만 선별한다. 누적·월간 지표, 등록·실사용 지표를 분리한다. 날짜·요일·포함 일수를 확인하고 혼동되는 일수 표기는 날짜만 남긴다.

## 디자인 선택

서로 다른 소수 디자인 후보를 실제 정부 샘플과 공식 출처로 보여준다. 이미 선택한 디자인은 재선택을 요구하지 않는다. 공공 블루 입체형은 따뜻한 흰 배경·남색 제목·파란 무광 오브젝트·넉넉한 여백을 활용한다. 정보 장은 숫자와 그래프, 참여 장은 분명한 행동 경로를 중심으로 배치한다. 이 스타일을 모든 요청에 강제하지 않는다.

[직접 생성한 표지 6종](references/generated-samples.md)에서 파란 입체형·메모지형·폴더형·기술 도해형·평면 정책형·사진형을 비교할 수 있다. 각 샘플은 이미지와 생성·편집 프롬프트를 함께 제공한다. 선택 후 해당 프롬프트를 읽어 새 원고에 맞게 재작성하고, 샘플의 기관 문구·날짜는 자동 승계하지 않는다.

## 프롬프트와 이미지

사용 가능한 image-prompt·codex-image 연결 스킬을 확인한다. 기획과 디자인이 승인되고 생성 요청을 받으면 확인 답변으로 멈추지 않고 실제 실행한다.

각 장의 정확한 카피, 제목·숫자·주석 위계, 색상, 여백, 오브젝트, 화면비를 독립된 UTF-8 프롬프트 파일로 저장한다. [타이포·생성·검수 기준](references/production.md)을 따른다.

모든 장의 프롬프트에 다음을 명시한다.
- 영역이 달라도 같은 위계의 글씨 크기·굵기는 동일하게 유지한다.
- 긴 문구만 작게 줄이지 않고 영역 폭과 줄 수를 조정한다.
- 줄바꿈은 한국어 의미·어절 단위로 지정한다. 조사·어미를 홀로 남기지 않는다.
- 숫자와 단위·날짜·주소는 한 덩어리로 유지한다.
- 같은 수준의 질문·정보 레이블은 같은 크기로 맞춘다.

외부 모델로 보낼 원문·참조 이미지의 권한을 확인한다. 첫 장을 실제 생성·확인한 후 그 생성물을 후속 장의 스타일 참조로 전달해 순차 생성한다. HTML 캡처나 글자 사후 합성으로 대체하지 않는다. 성공한 장은 보존하고 오류 장만 재생성한다. 인증 오류를 디자인 오류처럼 재시도하지 않는다.

## 검수와 전달

원고 대비 한글·숫자·단위·시점·참여 경로·주석을 대조하고 모든 이미지를 직접 확인한다. PNG decode·실제 크기·장수를 코드로 검사한다. 네이티브 화면비를 보존한다.

PNG 원본, 장별 프롬프트, manifest, 검수 기록을 ZIP으로 함께 전달한다. 미확정 정보를 표시하고 실제 게시 완료와 제작 완료를 구분한다. 메일 전송 요청 시 정확한 수신자·첨부를 확인하고 전송 후 보낸 메일의 수신자·제목을 읽어 검증한다. 성공 후 중복 발송하지 않는다.

## 안전과 공개

공식 제작 도구로 사칭하지 않는다. 고유 캐릭터·로고를 자동 복제하지 않는다. 내부 수치·문서·원고·생성물·인증정보·개인 경로를 공개 저장소로 복사하지 않는다. 공개에는 재사용 가능한 절차·비민감 템플릿 및 사용자가 범위를 지정해 공개 승인한 샘플만 포함한다. 이번 표지 6종의 승인을 다른 내부 산출물에 확대하지 않는다. 이미지 모델 이름만으로 실제 모델 버전을 확정하지 않는다.
