# 공공 카드뉴스

상태: 설계 초안. 자동 실행 스크립트는 아직 제공하지 않는다. 연결된 이미지 생성 스킬이 있어도 사용자 디자인 선택 전에는 실행하지 않는다.

## 시작
“공공 카드뉴스 만들어줘” 요청을 받으면 기획안 유무를 확인한다. 이미 기획안·장수·문구가 제공됐다면 다시 묻거나 전체 내용을 재작성하지 않는다.

## 기획안이 없는 경우
독자·목적·사실 근거·참여 경로 중 없는 필수 정보만 질문한다. 저장소 docs/TAXONOMY.md의 내용 구조 유형과 catalog/sources.json의 실제 샘플을 대조해 적합한 구성을 제안한다. 사용자가 문구와 세부 내용을 정할 수 있도록 장별 제목·핵심 메시지·필요 근거를 작성한다. 미확인 사실을 만들지 않는다. 승인 후 디자인 추천으로 이동한다.

## 디자인 선택
승인된 기획안에 맞는 서로 다른 디자인 후보를 실제 정부 샘플과 함께 제시한다. 적합한 이유와 밀도·장수 조정을 짧게 설명한다. 사용자 선택을 기다린다. 사용자가 고른 기존 디자인은 재선택을 요구하지 않는다.

## 프롬프트와 이미지
사용자 원문을 보존하여 각 장의 정확한 카피, 제목·숫자·주석 위계, 색상, 여백, 오브젝트, 화면비를 명시한다. 외부 모델로 보낼 원문과 참조 이미지의 권한을 확인한다. 첫 장부터 순차 생성하고 첫 결과를 다음 장의 스타일 참조로 사용한다. 실제 Codex 이미지 실행기를 사용하며 HTML 캡처로 대체하지 않는다. 성공 장은 보존하고 오류 장만 재생성한다.

## 검수와 전달
원고 대비 한글·숫자·단위·시점·참여 경로·주석을 대조하고 모든 이미지를 직접 확인한다. 완료 상태와 미확인 사항을 구분한다. PNG 원본, 장별 완성 프롬프트, 출처·검수 기록을 함께 전달한다. 자동 게시하지 않는다.

## 안전
정부·공공기관의 공식 제작 도구로 사칭하지 않는다. 원본 디자인의 고유 캐릭터·로고를 자동 복제하지 않는다. 내부 문서·인증정보·사용자 생성물을 공개 저장소로 복사하지 않는다. 이미지 모델 이름만으로 실제 모델 버전을 확정하지 않는다.
